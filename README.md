# Java Expense Tracker

A Java console application for managing and analysing personal expenses.

## Features

- Add and display expenses
- Search expenses by description
- Sort expenses by amount
- Calculate total, average and highest spending
- View category totals
- Identify unique categories
- Input validation and custom exception handling
- File-based persistence
- JUnit testing

## Technologies

- Java
- Maven
- JUnit
- Java Collections
- Java Streams
- File I/O

## Project Structure

The application uses object-oriented design with separate classes for expense data, application logic and exception handling.

## Running the Project

Clone the repository and run `Main.java` from your IDE.

## Running Tests

Run:

mvn test
